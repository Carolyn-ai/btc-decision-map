# 常见问题

| 现象 | 检查与处理 |
|---|---|
| ChatGPT 只能给命令，不能执行 | 进入桌面端 Codex 本地任务，确认文件与终端权限 |
| 找不到 Python | 准备官方 Python 3.12；3.14 尚不在本版支持范围 |
| 下载 Hugging Face/PyPI 失败 | 保留连接错误，检查网络后重新运行 setup.command；已有文件可以复用 |
| 模型校验失败 | 重新运行下载程序，不能跳过校验后冒充完整安装 |
| 端口被占用 | configure.command 修改端口；先 stop.command 再 start.command |
| 页面刚打开没有统计 | 等待约 60 秒新行情窗口，再核对实际记录 |
| 仍没有模型判断 | `.venv/bin/python scripts/doctor.py --model --market --live`，查看真实模型或行情错误 |
| Jev 未配置 | 可继续蓝绿路线；需要紫路时在本机配置页填写 Key |
| Jev HTTP 401/403/402 | 分别核对认证、模型权限及额度；免费额度不保证可用，查看提供方账户的实际状态 |
| Jev 达到调用上限 | 确认自己的用量后在配置页增加有限上限，重启；保留旧记录 |
| 网络回复迟到 | 记录为迟到，不进入严格共同题成绩；不事后补答 |

诊断回执和日志保存在本机 `data/`。分享故障时只提供必要错误摘要，隐藏 Key 和个人路径。不要提交整个账本或配置文件。
