# 观众复刻与修改手册

1. **跑通模型。** 先按首页指令安装，查看真实本机模型检查回执。小模型接受明确问题与有限选项，不是长篇聊天生成器。
2. **跑通公开数据。** 核对行情来源、接收时间及新鲜度。断网、过旧数据和时钟偏差都需要显示，不插入假价格。
3. **冻结问题。** 明确预测对象、时间范围、信息截止时间。先保存问题，再提交答案，避免看到结果后修改输入。
4. **做平行比较。** 蓝色直接 Laya、绿色方法改进、紫色可选 Jev 使用同轮冻结信息。保留绿色的原始模型答案和最终规则答案。
5. **建立核对记录。** 真实价格出现后标注结果；分别统计正确率、覆盖率、按时率和错误。不同方法比较必须有共同题分母。
6. **模拟执行。** 判断之外还要核对费用、风险、报价与成交条件。虚拟账户从自己的空记录开始；猜对不代表交易赚钱。
7. **做可理解的地图。** 点开每一步查看真实输入、判断、耗时和结果；回看标成历史回放。动画由账本事件驱动。
8. **尝试自己的场景。** 可以替换决策问题，例如“信息是否足够”“工单交给哪个部门”“是否应暂停一个流程”。先定义正确答案或人工复核方式，再做未来样本测试。

与 ChatGPT 协作时，可说：

> 请解释这轮三路判断为什么不同，引用保存的输入、原始答案、规则路线和真实结果，不重新调用模型补答历史。

> 请在一个新版本尝试修改绿色输入，保留旧版并固定新方法；设计未来共同题验证，先别把新方法成绩混进原账本。

> 请检查工作台为什么没有新记录，按模型、行情新鲜度、权限、额度和账本写入逐项定位，保留真实错误。

模型安装与数据接口是底座；把问题、规则、证据和反馈组织起来，才形成可复用的决策应用。
